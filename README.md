# Nexus GPT

Телеграм-бот с AI-моделями: чат, зрение (фото), распознавание голоса и видео.
aiogram 3 + OpenRouter (и совместимые провайдеры), токенная экономика,
оплата Telegram Stars и рублями, рефералка, админ-панель.

> Личный проект. Исходник выложен как резервная копия и портфолио.

## Возможности

- Чат-модели 4 категорий (Кодинг / Универсальные / Быстрые / Творчество),
  авто-перебор моделей при 429 и сбоях
- Фото → vision-модели автоматически
- Голос, аудио, видео, кружки → текст (Mistral Voxtral)
- Документы PDF/DOCX/TXT → в контекст запроса
- Баланс токенов, пакеты, Premium, ежедневный бонус со стриком, рефералы
- Оплата: Telegram Stars + Platega (СБП / карта / крипта)
- Админка: статистика, рассылка, промокоды, распродажи, баны, возвраты Stars,
  экспорт CSV, управление моделями, бэкап БД и кода
- `/selfedit` — бот переписывает собственный исходник через LLM с проверкой
  синтаксиса, бэкапом и авто-откатом; `/rollback`

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # заполнить токены
python app.py
```

Все секреты берутся из `.env` — в коде их нет. Файл `.env` коммитить запрещено
(см. `.gitignore`).

## Структура

| Файл | Что это |
|---|---|
| `app.py` | весь бот (один файл) |
| `.env.example` | шаблон переменных окружения |
| `requirements.txt` | зависимости |
